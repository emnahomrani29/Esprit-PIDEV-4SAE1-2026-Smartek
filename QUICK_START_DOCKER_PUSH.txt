📋 PRÉREQUIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Docker Desktop installé et démarré
2. Compte Docker Hub créé (https://hub.docker.com/signup)
3. Connecté à Docker Hub (docker login)
4. Au moins 10GB d'espace disque libre


🎯 MÉTHODE RAPIDE (WINDOWS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option 1 : PowerShell (Recommandé)
───────────────────────────────────
Ouvrir PowerShell et exécuter :

    .\Push-DockerImages.ps1 -Registry "VOTRE_USERNAME" -Tag "latest"

Exemple :
    .\Push-DockerImages.ps1 -Registry "johndoe" -Tag "v1.0.0"


Option 2 : Batch File
─────────────────────
Double-cliquer sur :
    push-docker-images.bat

Ou exécuter :
    push-docker-images.bat VOTRE_USERNAME latest


Option 3 : Git Bash
───────────────────
Ouvrir Git Bash et exécuter :

    ./scripts/build-and-push.sh --registry VOTRE_USERNAME --tag latest

🐛 PROBLÈMES COURANTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problème : "Docker n'est pas en cours d'exécution"
Solution : Démarrer Docker Desktop

Problème : "denied: requested access to the resource is denied"
Solution : docker logout puis docker login

Problème : "image not found locally"
Solution : Le script construira automatiquement les images

Problème : "unauthorized: authentication required"
Solution : docker login
